# Домашнее задание к работе 2

## Условие задачи
Составьте программу для определения сдачи после покупки в магазине товара:
перчаток стоимостью А руб., портфеля стоимостью Б руб., галстука стоимостью С руб.
Исходная сумма, выделенная на покупку – Д руб. В случае нехватки денег сдача
получится отрицательной.

## 1. Алгоритм и блок-схема

### Алгоритм

1. Начало

2. Задать исходные данные (конкретными значениями):
   - A = 500  — стоимость перчаток (руб.)
   - B = 2000 — стоимость портфеля (руб.)
   - C = 300  — стоимость галстука (руб.)
   - D = 3000 — выделенная сумма (руб.)

3. Вывести исходные данные:
   - Вывести A, B, C, D

4. Вывести общую стоимость покупки:
   - Вывести A + B + C

5. Вывести сдачу:
   - Вывести D − (A + B + C)

6. Конец

## 2. Реализация программы
#include <stdio.h>
#include <locale.h>

int main()
{
    setlocale(LC_CTYPE, "RUS");

    float A = 500.0f;   
    float B = 2000.0f;   
    float C = 300.0f;    
    float D = 3000.0f;   
    printf("\n--- Исходные данные ---\n");
    printf("Стоимость перчаток:  %.2f руб.\n", A);
    printf("Стоимость портфеля:  %.2f руб.\n", B);
    printf("Стоимость галстука:  %.2f руб.\n", C);
    printf("Выделенная сумма:    %.2f руб.\n", D);
    printf("\n--- Результат ---\n");
    printf("Общая стоимость:     %.2f руб.\n", A + B + C);
    printf("Сдача:               %.2f руб.\n", D - (A + B + C));

    return 0;
}
## 3. Результаты работы программы

Выделенная сумма:    3000.00 руб.

Сдача:               200.00 руб.
